# MiniMax H3 动态编译

进入本文件前，单元必须已在整片覆盖表中被判定为 `M` 或 `G`，并通过完成态预览验收。审批图与模型输入帧不是同一概念：审批图可以包含后期文字/UI；H3 只使用与其空间状态对齐的无字、无 UI `clean-base`。若 M01–M10 已提供状态机，H3 提示词复用其因果顺序和注意力逻辑，不逐帧照抄参考。

## 模式选择

- `I2VA`：配对的 `clean-base` 是精确首帧，从它开始变化。
- `L2VA`：配对的 `clean-base` 是精确终帧，运动最终收束到它。完成态审批默认优先评估此模式。
- `FL2VA`：首尾 `clean-base` 都已锁定，设计中间演化。
- `Ref2VA`：图片/视频只承担主体、风格或运动参考，不是精确端点。
- `T2VA`：没有锁定图像时使用；本工作流非首选。

先写模式选择原因。不要让一张“构图参考图”或带字审批预览被误当成精确首帧；模式判断以实际送入 H3 的 `clean-base` 为准。

## 编译输入

进入本阶段前必须具备：

- 用户已批准的 `final-composite-preview`，或无需后期文字/UI时由 `clean-base` 兼任的完成态审批图。
- 与审批图严格对齐、实际送入 H3 的 `clean-base`。
- 后期合成层：精确文字/UI、锚点、出现时机与最终稳定状态；没有则写“无”。
- 它在时间轴中的职责。
- 它在原始视频、脚本或 SRT 中实际覆盖的时间区间；不要与 H3 生成时长混淆。
- 保持项：主体身份、后期文字/UI锚点、布局、材质、色彩来源。
- 允许变化项：镜头、局部形变、内容进入方式、光的迁移。
- 精确 M 参考（若有）：文件与起止时间。
- 选定的 M01–M10 模式或新运动机制。

## 时间线骨架

一个单元只有一个主运动规律，安排 2–4 个强事件后刹车。示例骨架：

```text
0.0–2.0s  建立：从已锁定的无字输入底板开始，或建立将收束到终态的主体与空间
2.0–5.0s  强事件 1：主运动规律首次显现
5.0–8.0s  强事件 2：尺度/空间关系升级，不切换运动语法
8.0–11.0s 强事件 3：核心关系完成揭示
11.0–15.0s 收束：运动减速、光稳定，底板到达与完成态预览对齐的终态；文字/UI由后期落版
```

时长应服从用户目标和模型限制；不要为了填满时间增加无关事件。

## 提示词行文

最终可复制提示词不是分析清单，而是一段能让模型读出连续影片的导演描述。参考范例只用于抽象写法，不继承范例里的时长、人物、题材、配色、音乐或镜头内容；这些仍由当前脚本、批准的完成态预览、配对底板和所选运动模式决定。

按以下顺序组织：

1. 开头一次锁定时长、画幅、输入帧职责、媒介和全局视觉规则。
2. 先说明全片不变的空间、主体、色彩来源、运动方向或镜头规律，再进入具体动作。
3. 用时间段或自然段描述连续演化。每个关键动作都写清“什么对象 → 朝什么方向/以什么方式变化 → 形成什么结果”，并用“随后、顺势、紧接着、最终”等因果连接词维持同一条运动链。
4. 转场必须从前一动作中产生，例如主体越过画面形成擦除、遮罩完整覆盖后换底图、笔触写完触发落版；不把转场作为与内容无关的效果列表。
5. 结尾明确运动如何减速、停在哪里、最终必须保持什么可读关系。连续性和少量针对性排除项统一放在末尾。

行文使用具体动作动词和可见结果，避免只堆“高级、电影感、震撼、丝滑”等评价词。单一短动效不为凑格式虚构音乐、音效或多余分镜；音频只在用户提供或当前任务确实需要时编入。H3 动态层不负责生成可读文字或真实 UI；完成态预览中的标题、字幕、标签和 UI 只作为审批与后期排版依据，实际生成使用同构图、同完成状态的无字、无 UI 底板，精确内容交给后期合成。

## 固定尾注

每一条最终可复制的 H3 提示词都必须以下列原文作为最后一行。不得改写、缩写、合并到其他句子、提前放置或遗漏：

```text
【禁止项】 文字/UI/水印/Logo/角标/可读文字/真实UI 【强制声明】 无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)。
```

```markdown
对应视频时间：09:59.733–10:34.900

---

- 模型输入帧：clean-base 文件；首帧 / 终帧 / 首尾帧 / 参考
- 后期合成层：精确文字/UI、锚点、出现时机；无则写“无”
- 输入帧职责：
- 主运动规律：
- 保持项：
- 允许变化项：
- M 参考：文件 @ 时间段；只借用什么

【可复制提示词】
（用连续导演语言依次写：全局锁定 → 起始状态 → 动作因果链/按秒时间线 → 镜头与空间 → 材质与色彩行为 → 收束状态 → 连续性约束。不要把这些括号标题原样复制进提示词。最后原样追加“固定尾注”。）
```

时间标头属于剪辑定位信息，不放进可复制提示词的代码块。源素材没有时间码时，按 `SKILL.md` 的全局输出包络标记为待回填，不自行推测。

## 连续性约束

只写与当前画面相关的约束：

- 主体身份、几何和材质不漂移。
- 不要求 H3 书写、改写或保持可读文字；标题、字幕、标签和真实 UI 使用后期合成。
- 不凭空新增图标、卡片、按钮或次级 UI。
- 颜色沿已锁定的光学/材质机制变化，不随机换色。
- 镜头运动不与主体运动争夺注意力。
- 终段减速并保持核心信息可读。
- 精确长文字、数据表或 UI 标签只存在于完成态预览和后期合成层，不进入 H3 动态底板。

## 生成后反馈

若用户提供实际生成视频：

1. 均匀取帧并查看关键时间点。
2. 对照静帧锁定项和时间线找首个偏离点。
3. 只修正主要偏离源：输入帧职责、运动动词、镜头、保持项或时间分配。
4. 未经用户确认，不把失败样片加入参考库。
5. 用户明确认可后，可询问是否作为正向成片案例入库。
