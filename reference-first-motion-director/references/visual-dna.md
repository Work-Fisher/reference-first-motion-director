# 主知识库视觉 DNA

这套审美不是一张“高级色卡”，而是注意力、证据和状态变化的系统。依据来自 `剪辑学习/GIF`、Seedream5 全片拆解、M02–M10 已验证复刻与代表性视觉素材。

## 1. 高级感的优先级

```text
画面职责清楚
  > 信息关系真实
  > 主体与尺度明确
  > 状态变化有因果
  > 色彩与材质有来源
  > 装饰细节
```

如果人物、证据、录屏和包装职责错了，黑底、光效、衬线字也救不了画面。

## 2. 构图语法

### 原生证据满屏

真实作品、结果、页面和比较内容尽量获得完整横向空间。人物在证据前提出问题、证据后给判断，不长期压在信息密集画面上。

### 先建立容器，再落入内容

M03–M05/M09 常先出现槽位、编辑框、选择框或卡带，再让图片/文字进入。容器不是装饰卡片，而是让观众提前理解“这里将出现几项、它们是什么关系”。

### 文字作为空间主体

标题可用巨大尺度、描边到填充、裁切、透视和重复建立空间。短词可以成为主角；长段说明必须退到旁白或真实界面，不用模型生成密集小字。

### 负空间制造尺度

黑场、深灰场或大块留白用于让唯一主角获得重量。负空间不是把所有元素缩小，而是明确中心、边界和视线终点。

### 同骨架连续变化

颜色切换、候选比较、章节组与作品长廊必须锁定几何骨架。变化发生在状态或内容，不让每一帧重新发明版式。

## 3. 色彩语法

### 色彩必须属于某个来源

- 原生作品颜色：作品墙和页面旅程保留内容自身色彩。
- 界面状态颜色：M02 的蓝/绿/紫/红/橙对应被点击状态。
- 光学颜色：`bed50c362785.mp4` 或 Optical Layer Lock 中由折射、玻璃、体积光产生。
- 环境颜色：深红/青绿来自空间光场，必须照到主体或影响材质。
- 强调颜色：蓝紫手写线、黄色目标框、酸绿路径只标记单一重点。

不要把颜色仅当抽象分类标签。尤其不能把“温暖、治愈、知识、数据”等名词自动翻译成米白、暖黄、象牙色和若干圆角色块。

### 当前可复用色彩机制

- **深灰颗粒 + 白色衬线 + 蓝紫手写签名**：M05/M10 的编辑落版语法。
- **黑/深海军蓝 + 透明玻璃层 + 奶白主字 + 极小酸绿点**：Optical Layer Lock；适合克制的单词英雄帧。
- **黑场 + 青绿体积场 + 黑色核心**：Emotion Field；适合一个概念向外展开，不能变成通用数据背景。
- **黑/深红 + 原生界面高光**：Agent Workspace；只用于真实系统旅程，不用于抽象解释。
- **黑/红硬切 + 巨字/轨道**：Script Evidence Journey；适合强制、冲突、约束和编辑拆解。
- **深黑棕 + 低饱和金/奶白细字**：Archive Scroll；只适合真实长表/档案浏览。

## 4. 字体与层级

- 英文大标题可使用高反差编辑衬线；中文标题使用有力量的宋/衬线或克制黑体，字体选择服从语义。
- 一帧最多一个英雄级文字层；副标题、编号和技术标记明显降级。
- 描边表示草稿/未确认，实心表示落版；二者是状态，不是同时堆叠的装饰。
- 小英文、坐标、控制点只提供编辑语境，亮度和信息权重必须低。
- 手写线/签名晚于主标题到达，只做一次人格化收尾。

## 5. 运动语法

### 因果优于漂亮

鼠标先到、按钮再按、状态再切；目标先上移、其他行再让位；输入先出现、候选再展开。观众能说出“为什么变”，运动才成立。

### 短促进入，稳定阅读

图形常在 8–16 帧内进入，之后停住。复杂片段的最终状态总比过程稳定；不使用无休止的呼吸、漂浮和旋转维持“动感”。

### 累积而非轮播

M07 的证据点依次增加并保留；M06 的区域、动作、关系、指令分层增加。需要建立完整论证时，旧信息不能为腾位置而不断消失。

### 单一连续曲线

长位移、透视推进和排行变化使用一条连续运动轨迹。不要在每对关键帧之间重新套相同缓动，造成反复减速/启动。

### 遮罩必须承担叙事功能

白幕、闪光或体积光不只是“好看转场”，它应同时解释系统处理、清空旧标注和隐藏换图接缝。

## 6. 纹理与辅助层

- 纸张褶皱、扫描线、灰尘、网格、点阵和模糊光场都是辅助资产，不是主体。
- 纹理应低对比并与表面/镜头发生关系；直接铺一层“高级颗粒”不能替代材质。
- 素材池中的红蓝舞台光、胶片灰尘、纸纹、网格和片尾素材属于实用覆盖层，不自动进入审美参考契约。

## 7. 信息图失败的上游根因

错误链路：

```text
脚本名词 → 每个名词画一个图标 → 放进多个圆角卡片 → 随手分配暖色/分类色
```

修正链路：

```text
判断/证据/操作/关系
  → A/E/R/M/G 职责
  → 真实信息关系
  → M01–M10 或单一新机制
  → P/C/M 精确参考
  → 英雄帧
```

问题不在某一种色名，而在“对象清单”替代了真实关系。因此先改职责与模式，不靠叠加禁令。

## 8. 案例使用边界

- 原始 9 GIF 与明确通过复刻可以作为运动依据。
- `motion-lab/out/*review*`、旧版本和实验作品只在视觉查看后提取明确机制。
- Flova 系列证明了一些有效结构，但其中界面卡片、长表和颜色不是全局默认。
- 素材收集里的背景、网格、灰尘和片尾梗图不是“高端审美样本”。
- 新参考入口的 22 项候选见 [inbox-reference-catalog.md](inbox-reference-catalog.md)，每次仍需查看精确源帧。
