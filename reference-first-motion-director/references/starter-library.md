# 随包 starter library

内置库是所有安装者都能使用的只读基线，不需要配置本机路径。它包含 4 支 720p 轻量 MP4、逐支 12 帧联络表和人工机制标注：

| 模式 | 案例 | 主要学习内容 |
|---|---|---|
| M02 | 信号配色状态切换 | 固定构图、单变量换色、状态索引、斜向色闸 |
| M03 | 模块化构图组装 | 空网格、矢量模块依次锁定、白闪、完成态 |
| M05 | 编辑式章节标题栈 | 导线建立、描边显影、实字收束、三层信息层级 |
| M10 | 节拍式标题钉合 | 方向对撞、斜切、规则线、编号徽章钉合 |

先用 `search` 查看机制标注，再用 `preview` 返回随包联络表；需要观察时间曲线时打开记录中的 MP4。内置案例是结构导航，不是四个固定模板。选择案例后只继承信息关系、注意力顺序、色彩行为或运动规律，不继承演示文案、虚构品牌和完整布局。

内置库只读。`index`、`add` 和 `annotate` 始终写向个人参考库；要扩展案例时先运行 `configure`。个人库与内置库会合并检索，SHA-256 相同的素材优先使用个人记录并自动去重。

来源边界记录在 `assets/starter-library/manifest.json`：随包只包含仓库内 Python 源码确定性绘制的纯矢量帧、由这些帧编码的 MP4 和联络表。执行 `assets/starter-library/source/render_original_starter_library.py` 可以重新生成全部四支案例。其他博主、网站、课程或个人参考库中的图片、视频、截图、工程资产、字幕和拆帧均未分发。

正常使用内置库不需要渲染依赖；只有重新生成公开资产时才需要 Pillow 与 FFmpeg。
